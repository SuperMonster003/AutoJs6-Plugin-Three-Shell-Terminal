# v1.1.0

###### 2026/10/07

* `기능` 타사 Node.js Runtime 서명 신뢰: 환경 진단 화면이 비공식 서명의 SHA-256을 표시하고 "이 서명 신뢰"를 제공하며, 한 번 더 확인하면 새 세션에서 해당 node / npm 명령을 사용할 수 있습니다. 설정의 "신뢰하는 Node.js 서명"에서 언제든지 취소할 수 있습니다
* `기능` 명령 완료 알림: 대화형 셸 없는 명령 (예: 스크립트가 `keepOpen: false`로 호출한 `exec`)이 스스로 끝나면 알림을 보내고, 탭하면 출력 끝부분을 보여 주어 복사, 공유하거나 해당 디렉터리에서 터미널을 다시 열 수 있습니다. 알림에는 세션 번호와 디렉터리만 표시되고, 연속된 알림은 한 번만 울리며, 설정에서 끌 수 있습니다
* `기능` 터미널 색상과 글꼴: 설정에 "터미널 색상" (밝은 / 어두운 모양 따르기, 어둡게, 밝게, 테마 색상으로 물들이기)과 "터미널 글꼴" (시스템 고정폭 또는 합자 없는 내장 JetBrains Mono)이 추가되었습니다. 선택 레이어와 명령 출력 화면도 같은 글꼴을 사용하며, 터미널로 돌아오면 세션을 유지한 채 적용됩니다
* `기능` 파일 관리자 디렉터리 메뉴의 "터미널에서 열기"를 이제 플러그인이 제공합니다 (AutoJs6 6.8.0 빌드 5320 이상). AutoJs6는 선택한 디렉터리의 경로만 전달하며 추가 권한을 부여하지 않습니다. 가장 최근 세션이 해당 디렉터리로 이동하고, 세션이 없으면 그곳에서 새 세션을 시작합니다. 이전 AutoJs6 빌드는 자체 메뉴 항목을 계속 표시합니다
* `수정` Android 17 등 최신 버전에서 터미널을 길게 누르면 선택 핸들과 "복사 / 모두 선택" 도구 모음이 다시 표시되어 텍스트를 선택하고 복사할 수 있습니다
* `수정` 매우 긴 터미널 기록을 복사하거나 공유해도 플러그인이 더 이상 충돌하지 않습니다 (Android 7.0에서는 충돌로 모든 세션이 종료되었습니다); 너무 긴 경우 최근 100000자만 사용하고 안내를 표시합니다
* `의존성` jackpal emulatorview 패치를 1.0.42-p6.1 -> 1.0.42-p8.1로 업그레이드: 플러그인이 렌더러 글꼴을 설정하고, API 23에서 SDK에서 빠진 `android.util.FloatMath`를 `Math.ceil`로 대체했습니다. 다른 클래스는 바이트 단위로 동일하며 `locks/vendored-aars.lock`을 갱신했습니다
* `의존성` 선택 가능한 터미널 글꼴로 JetBrains Mono NL 2.304 (SIL Open Font License 1.1)를 추가했습니다. 수정 없이 포함하고 라이선스를 정보 화면에 표시하며, 출처와 SHA-256은 `vendor/fonts/jetbrains-mono/`에 기록되어 있습니다
* `의존성` 파일 관리자 디렉터리 작업을 위한 Explorer Action 프로토콜 v23 계약으로 `explorer-action-api.aar` (AutoJs6 모듈 `plugin-api/explorer-action-api`, 호스트 빌드 6.8.0 / 5320, MPL 2.0)를 추가했습니다. 해시는 `locks/host-api-aars.lock`에 고정되어 있습니다

# v1.0.0

###### 2026/10/07

* `힌트` 1.0.0은 독립 터미널, 백그라운드 세션, 대화형 스크립트 API와 설정을 제공합니다. 전체 스크립트 API는 AutoJs6 6.8.0 빌드 5315 이상이 필요하며, 기본 플러그인 프로토콜은 빌드 5304부터 지원합니다. Android 7.0 이상을 지원합니다
* `기능` 다중 세션: 생성, 전환, 종료와 세션 관리자. 화면을 떠난 뒤에도 포그라운드 서비스가 세션을 유지하며, 알림에 현재 디렉터리와 세션 수, "세션 종료" 동작을 표시합니다
* `기능` 터미널 화면: 두 줄 키 바 (Esc / Tab / Ctrl / 방향키 / 자주 쓰는 기호), 네이티브 텍스트 선택과 복사 / 전체 선택, 기록 복사와 공유, 글자 크기, 붙여넣기와 지우기
* `기능` Node.js 도구 체인: Node.js Runtime 플러그인 (1.5.0+) 을 설치하면 node / npm / npx / corepack / yarn / pnpm 을 사용할 수 있고, npm 레지스트리와 "설치 스크립트 무시" 설정, 패키지 메뉴 (npm init / install / run script 등) 도 제공됩니다
* `기능` AutoJs6 진입점: 홈 드로어 스위치 (세션 수, 전체 종료), 파일 관리자 디렉터리 메뉴와 프로젝트 도구 모음의 "터미널에서 열기"
* `기능` 스크립트 API `terminal` (별칭 `$terminal`): 세션 관리, 보이는 실행 (`exec`, `npm.run`), `output` / `exit` 이벤트와 `write`, `waitFor` 를 갖춘 세션 객체. 모든 실패는 안정적인 `code` 를 가진 `TerminalError` 입니다
* `기능` 독립 앱: 런처 아이콘이 바로 터미널을 열고, 설정 페이지 (AutoJs6 를 따르는 외관, 글자 크기, npm 레지스트리, Node.js 통합, 모든 파일 접근, 터미널 데이터 지우기), 정보와 릴리스 기록을 제공합니다
* `기능` ABI 별 APK (arm64-v8a, armeabi-v7a, x86_64, x86) 와 universal APK, 16 KB 페이지에 정렬된 네이티브 라이브러리
* `기능` 10 개 언어의 README, 플러그인 센터 안내, 변경 기록
* `수정` 시스템이 백그라운드 활동을 제한해도 세션 시작 시 플러그인이 충돌하지 않습니다. 세션은 포그라운드 서비스 보호 없이 계속 실행됩니다.
* `수정` 긴 출력 기록은 최신 텍스트를 유지하면서 프로세스 간 응답 크기 제한을 넘지 않도록 합니다.
* `수정` 스크립트 출력 읽기 및 재생 시 화면을 채우는 끝부분의 빈 줄을 제거하고 프롬프트 공백과 후속 출력의 줄 경계를 유지
* `수정` 시작 중인 세션이 호스트 조회에서 일시적으로 사라져 화면에 표시되는 실행에서 터미널을 열 수 없던 문제
* `수정` 대량의 연속 출력이 터미널 메시지 큐를 차단하지 않으며, 시작 중 세션 종료와 자식 프로세스의 정상 종료 시 pty와 입출력 스레드를 해제
* `수정` 백그라운드 제한으로 포그라운드 서비스가 시작되지 않은 경우 기존 터미널을 열 때 보호 시작을 다시 시도
* `수정` 플러그인 프로세스 종료 후 작업을 다시 열면 새 셸을 만들며 이전 명령을 다시 실행하지 않음
* `개선` 런처와 플러그인 센터 아이콘의 시각적 크기를 통일하고 투명 배경과 흑백 또는 중성 회색조 적용
* `개선` 플러그인 센터 아이콘에 Icon Studio에서 조정한 크기, 위치, 밝은 이미지와 어두운 이미지 및 원형 배경을 적용하고 재생성 가능한 원본과 매개변수를 유지
* `개선` Android 앱 정보 아이콘에 Icon Studio의 그림과 밝은 배경 및 어두운 배경을 사용하고 플러그인 센터의 투명 그림과 기존 런처 옵션을 유지
* `의존성` 터미널 에뮬레이션과 pty 네이티브 라이브러리로 jackpal Android-Terminal-Emulator (term 1.0.70, emulatorview 1.0.42-p6.1, libtermexec 1.0, Apache-2.0) 추가, `locks/vendored-aars.lock` 에 해시 고정
* `의존성` 공유 플러그인 계약과 Node.js 매니페스트 계약으로 `common-plugin-api.aar` 와 `nodejs-api.aar` (AutoJs6 모듈 `plugin-api/common-plugin-api` 와 `plugin-api/nodejs-api`, 호스트 빌드 6.8.0 / 5303, MPL 2.0) 추가, `locks/host-api-aars.lock` 에 해시 고정
* `의존성` 터미널 계약 V1 (`ITerminalPlugin` / `ITerminalCallback`, 신원, 상한, 오류 코드) 로 `terminal-api.aar` (AutoJs6 모듈 `plugin-api/terminal-api`, 호스트 빌드 6.8.0 / 5304, MPL 2.0) 추가. 플러그인 신원 상수는 이제 여기서 가져오며 `locks/host-api-aars.lock` 에 해시 고정
