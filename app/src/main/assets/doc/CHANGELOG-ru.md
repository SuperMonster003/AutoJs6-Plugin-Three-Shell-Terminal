# v1.0.0

###### 2026/10/07

* `Подсказка` Версия 1.0.0 предоставляет отдельный терминал, фоновые сеансы, интерактивные API сценариев и настройки. Полные API требуют AutoJs6 6.8.0 сборки 5315 или новее; базовый протокол требует сборку 5304. Поддерживается Android 7.0 и новее
* `Функция` Самостоятельный плагин 3-Shell Terminal с обнаружением хостом, управлением терминалом и защищёнными входами в интерфейс и настройки
* `Функция` APK по ABI (arm64-v8a, armeabi-v7a, x86_64, x86) плюс универсальный APK, нативные библиотеки выровнены по страницам 16 КБ
* `Функция` README, описание для центра плагинов и журнал изменений на 10 языках
* `Функция` Ядро сеансов перенесено из терминала хоста: сеансы оболочки на pty с реестром на уровне процесса (заголовок и код выхода записываются для Binder), окружение сеанса и структура каталогов внутри собственного каталога файлов плагина, обнаружение лаунчера Node.js с установщиком npm / corepack, а также служба переднего плана, поддерживающая сеансы, с уведомлением "Закрыть сеансы" (канал `three.shell.terminal.sessions`)
* `Функция` Определение доступа к хранилищу (`StorageAccess`): собственное состояние разрешений плагина (устаревшие разрешения времени выполнения ниже API 30, "Доступ ко всем файлам" начиная с API 30), распознавание общего хранилища для `/sdcard`, `/storage/...` и собственных папок `Android/{data,obb,media}`, откат начального каталога к `$HOME` с `STORAGE_PERMISSION_REQUIRED` или `DIRECTORY_INACCESSIBLE`, а также Intent настроек, открывающие доступ ко всем файлам
* `Функция` Интеграция Node.js с доверием к подписи (`NodeCliTrust`, `NodeCliLocator`, `SessionAssembly`): плагин Node.js Runtime используется только если он подписан официальным ключом плагинов AutoJs6 или собственным ключом этого плагина, переключатель в настройках срабатывает раньше любого поиска, каждый результат отображается на состояния `node-cli` контракта (`available`, `disabled`, `plugin-missing`, `plugin-untrusted`, `plugin-too-old`, `executable-missing`, `exec-denied`, `setup-failed`), а каждый запуск сеанса обновляет ссылки команд в `usr/bin`, распаковывает архив npm / corepack один раз на дайджест и экспортирует окружение npm / corepack
* `Функция` AutoJs6 может создавать и управлять до 16 сеансами терминала, получать вывод в реальном времени через 4 слушателя на сеанс, читать недавний вывод и запрашивать окружение shell. Закрытие AutoJs6 не завершает сеансы; неверные запросы отклоняются с указанием причины.
* `Функция` npm init, установка зависимостей/пакетов, поиск/запуск сценариев package.json и поиск npm; реестры npmjs, npmmirror, пользовательские HTTPS-реестры и настройка ignore-scripts. Очистка данных закрывает сеансы и пересоздаёт личные home/usr, сохраняя настройки и внешние проекты
* `Функция` Экран терминала (`TerminalActivity`): интерфейс терминала хоста перенесен на собственную тему Material 3 плагина, с панелью клавиш (Esc / Tab / Ctrl / Alt / стрелки / листание), изменением размера текста щипком, выделением текста долгим нажатием и копированием, меню сеансов / текста / управления пакетами / настроек / справки, подзаголовком панели инструментов, который показывает каталог оболочки и копирует его по касанию, и баннером Node.js, который объясняет отсутствие, недоверенность, устаревание или отключение Node.js Runtime и предлагает действия установить / обновить / включить / подробности; баннер хранилища появляется, когда в каталог общего хранилища нельзя войти, и предлагает "Предоставить" и "Войти в каталог снова"; экран следует языку, ночному режиму и цвету темы хоста через поставщик настроек хоста и возвращается к системным значениям с общим цветом `#FFDEAD`
* `Функция` Диспетчер сеансов: диалог со сворачиваемыми разделами состояние / управление / сеансы / настройки, который перечисляет все работающие сеансы с каталогом, PID и временем работы, открывает или закрывает отдельный сеанс, создает новый, закрывает все, показывает сведения о сеансе с копированием и предлагает настройки размера текста, реестра npm и ignore-scripts; он использует тот же реестр сеансов, что и `onSessionsChanged` хоста, открывается из меню терминала, из уведомления о сеансах (касание) и, для входа хоста `manager=true`, через прозрачную `TerminalManagerActivity`, которая после закрытия не оставляет терминала
* `Функция` Вход хоста и лаунчер: экспортируемая входная Activity `TERMINAL_OPEN`, защищенная разрешением подписи `org.autojs.permission.PLUGIN`, проверяет вызывающего, которого может назвать (разрешение получено, подпись совпадает с плагином), сверяет extras `directory` / `sessionId` / `newSession` / `command` / `manager` с ограничениями контракта и передает их экрану терминала в собственной задаче или диспетчеру сеансов поверх вызывающего; `LauncherActivity` (цель псевдонимов значка) восстанавливает последний сеанс или запускает новый в домашнем каталоге; Назад из терминала, открытого хостом, возвращает к хосту, из лаунчера на главный экран, а задача терминала покидает недавние, поэтому запрос запуска никогда не воспроизводится повторно
* `Функция` Выбор значка запуска: четыре activity alias `MAIN / LAUNCHER` поверх приватного перенаправителя лаунчера (адаптивный светлый, адаптивный тёмный, адаптивный автоматический, прозрачный фон), по умолчанию включён автоматический значок; выбор сохраняется PackageManager как единственный включённый alias, восстанавливается при каждом открытии экрана и после обновления пакета, а закреплённые и динамические ярлыки переносятся на выбранный alias
* `Функция` О приложении, история версий и проверка обновлений: экран "О приложении" с установленной версией, номером и датой сборки, разработчиком, лицензией плагина (MPL 2.0) и разделом сторонних компонентов, который офлайн открывает встроенные лицензию и уведомление jackpal Android-Terminal-Emulator (Apache-2.0), уведомления API плагинов AutoJs6 (MPL 2.0) и уведомления библиотек; экран документа, отображающий встроенный журнал изменений на текущем языке (с откатом на английский) без WebView; и ручная проверка обновлений, которая обращается к GitHub Releases API только по HTTPS, может быть отменена, имеет тайм-аут, повторно использует ответ 12 часов, игнорирует выбранную версию и предлагает страницу выпуска или встроенную историю. В меню переполнения терминала добавлен пункт "О приложении"
* `Функция` Отдельная страница настроек из трёх групп: внешний вид с языком, ночным режимом, цветом темы и значком лаунчера (каждый по умолчанию следует AutoJs6; цвет темы предлагает 16 предустановок и ввод HEX / rgb()), терминал с размером текста, реестром npm, ignore-scripts, переключателем интеграции Node.js, экраном проверки окружения, доступом ко всем файлам и очисткой данных, и сведения с проверкой обновлений, историей версий и разделом "О приложении". Диалоги выбора подтверждают перед применением, изменения вступают в силу сразу. Пункт "Настройки" в меню переполнения терминала открывает страницу напрямую (подменю быстрых настроек убрано), центр плагинов AutoJs6 попадает на неё через TERMINAL_SETTINGS, и плагин теперь объявляет возможность settings
* `Исправление` Системное ограничение фоновой активности больше не вызывает сбой плагина при запуске сеанса. Сеанс продолжает работу без защиты службы переднего плана.
* `Исправление` Чтение длинного вывода сохраняет последний текст в пределах допустимого размера межпроцессного ответа.
* `Исправление` Чтение и воспроизведение вывода пропускают пустые строки заполнения экрана, сохраняя пробелы приглашения и границу перед новым выводом
* `Исправление` Запускающийся сеанс мог кратковременно исчезнуть из запросов хоста, мешая открыть его терминал при выполнении с отображением
* `Исправление` Непрерывный вывод больше не блокирует очередь сообщений терминала; закрытие при запуске и естественное завершение освобождают pty и потоки ввода-вывода
* `Исправление` Открытие существующего терминала повторяет запуск защиты службы переднего плана, если ему помешали фоновые ограничения
* `Улучшение` Единый визуальный размер значков лаунчера и Центра плагинов, прозрачный фон и черно-белые изображения или нейтральные оттенки серого
* `Улучшение` Значки центра плагинов используют размеры, положение, светлые и тёмные изображения и круглые фоны, настроенные в Icon Studio, сохраняя исходники и параметры для воспроизведения
* `Улучшение` Значки в сведениях о приложении Android используют изображения и светлый и тёмный фон Icon Studio, сохраняя прозрачные изображения центра плагинов и существующие варианты значков лаунчера
