3-Shell Terminal はスマートフォン上の対話型ターミナルです. システムの `/system/bin/sh` を pty で実行し, 複数のセッションを同時に開くことができ, 画面を離れてもセッションはバックグラウンドで動き続けます. Node.js Runtime プラグインを入れると node や npm などのコマンドも使えます. AutoJs6 の "ターミナル" 入口とスクリプトの `terminal` オブジェクトは, どちらも本プラグインが提供します.

### はじめに

1. AutoJs6 のホームのドロワーで "ターミナル" をタップするか, ファイルマネージャーのフォルダーメニューで "ターミナルで開く" を選びます. ホーム画面の 3-Shell Terminal アイコンをタップしても開けます.
2. コマンドを入力して Enter キーで実行します. 画面下部のキーバーには Esc, Tab, Ctrl, 方向キー, よく使う記号があります.
3. ツールバーの "セッション" メニューでセッションを作成, 切り替え, 終了します. 画面を離れてもセッションは動き続け, 通知をタップすると "ターミナル管理" を開けます.
4. `/sdcard` などの共有ストレージのフォルダーに入る前に, ターミナルの案内に従って "許可する" をタップするか, 設定で "すべてのファイルへのアクセス" をオンにします.

### 主な機能

- **複数セッション**: セッションの作成, 切り替え, 終了ができ, "ターミナル管理" ですべてのセッションを一覧できます. フォアグラウンドサービスがバックグラウンドでセッションを維持し, 通知に現在のフォルダーとセッション数を表示します.
- **ターミナル画面**: キーバー, テキストの選択とコピー, "出力ログを共有", 2 本指での文字サイズ変更に対応します. 設定では "端末の配色" を 4 種類, "端末のフォント" を 2 種類から選べます.
- **コマンドエディター**: 複数行や長いコマンドを貼り付けると, まず全文を表示します. 現在のセッションに貼り付けるか, 新しいセッションで実行して終了コードを確認できます.
- **Node.js ツールチェーン**: Node.js Runtime プラグインを入れると node, npm, npx, corepack (yarn / pnpm) が使えます. 設定で "npm レジストリ" を選んだり, "npm ライフサイクルスクリプトを無視" をオンにしたりできます.
- **コマンド完了の通知**: スクリプトが対話型 shell を残さずに実行したコマンドが終わると通知が届き, タップすると出力の末尾を確認できます. 設定で "コマンド完了の通知" をオフにできます.
- **個別の設定**: 言語, 夜間モード, テーマカラーは既定で AutoJs6 に従い, 個別にも設定できます. ランチャーアイコンは 4 種類のスタイルから選べます. AutoJs6 が対応していれば, 設定ページのメニューに "共通設定ページを開く" が表示されます.

### スクリプトでの使い方

スクリプトはグローバルオブジェクト `terminal` (別名 `$terminal`) で, セッションの作成, コマンドの実行, 入力の書き込み, 出力の監視を行います:

```js
if (!terminal.isAvailable()) exit();
let result = terminal.exec('uname -m', {
    show: false,
    keepOpen: false,
    wait: true,
});
console.log(result.exitCode);
let session = terminal.open({ show: false });
session.on('output', (text) => console.log(text));
session.write('ls\n');
session.show();
```

- `exec` は既定でコマンド終了後も対話型 shell を残します. 終了コードを待つには `keepOpen: false` と `wait: true` を両方指定します.
- 同期メソッドはスクリプトのスレッドをブロックするため, UI スレッドでは呼び出せません. ほとんどのメソッドには Promise を返す `Async` 版もあります.
- スクリプトが終了してもセッションは動き続けるため, 不要になったら `session.close()` を呼び出します. 操作に失敗すると `code` 付きの `TerminalError` がスローされます.
- すべてのオプションとイベントは [AutoJs6 ドキュメント > ターミナル](https://docs.autojs6.com/#/terminal) を参照してください.

### 動作要件

- Android 7.0 以降, AutoJs6 6.8.0 以降.
- node や npm などのコマンドには [Node.js Runtime](https://github.com/SuperMonster003/AutoJs6-Plugin-NodeJs-Runtime) プラグイン 1.5.0 以降が必要です.
- 共有ストレージのフォルダーに入るには "すべてのファイルへのアクセス" (Android 11 以降) またはストレージ権限が必要です. 通知権限はセッションの通知とコマンド完了の通知に使います.
- コマンドは本プラグイン自身の ID と権限で実行され, AutoJs6 の権限は引き継ぎません. AutoJs6 の権限が必要なコマンドは, スクリプトで `shell()` を使ってください.

### よくある質問

**`/sdcard` 内のフォルダーに入れない**

本プラグインには独自のストレージ許可が必要です. ターミナルの案内に従って "許可する" をタップするか, 設定で "すべてのファイルへのアクセス" をオンにしてください. Android 10 以前はストレージ権限を付与すれば十分です. `content://` のアドレスはファイルパスではないため, 入ることはできません.

**node コマンドが見つからない**

Node.js Runtime プラグインがインストールされ, 設定の "Node.js 連携" がオンになっていることを確認してから, "Node.js ランチャーの確認" を開いて原因を確認してください. プラグインの署名が公式の署名でない場合, そのページに署名の SHA-256 が表示され, 信頼を確認すると新しいセッションで使えるようになります.

**バックグラウンドのセッションがシステムに終了される**

システムがプラグインのプロセスを終了すると, セッションは復元できません. HyperOS や MIUI などはバックグラウンド動作を制限することがあるため, システム設定で 3-Shell Terminal の通知とバックグラウンド実行を許可してください.

キー, スクリプトインターフェース, 権限の詳細は [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Shell-Terminal) を参照してください.
